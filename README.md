# Automatic File Organizer

A smart and efficient Python script that declutters your messy folders (like the `Downloads` directory) by automatically organizing files into categorized subfolders based on their extensions.

## ✨ Features
* **Zero Manual Effort:** Creates folders and moves files instantly.
* **Smart Categorization:** Automatically groups files into:
  * 📸 `Photos` (.jpg)
  * 🎥 `Videos` (.mp4)
  * 📄 `Doc` (.docx)
* **Safe Execution:** Automatically ignores the script file itself to avoid self-displacement.
(note: other files type like pdf will added soon.)
## 🛠️ Built With
* Python 3
* `os` module (Built-in)
* `shutil` module (Built-in)

## 🚀 How to Run
1. Place the `organizer.py` script inside the messy folder you want to organize.
2. Put some test files (images, videos, or documents) next to it.
3. Open your terminal or command prompt in that directory.
4. Run the script using the following command:
   ```bash
   python organizer.py
   ```
5. Watch the magic happen in your file manager!
